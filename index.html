mii-kds-module-template

GitHub template repository to start an MII Kerndatensatz module Implementation Guide — Forschungsgruppe Digital Health, TU Dresden.

Click Use this template on the repository to create a module. You get the MII page structure, a bilingual (English/German) build, pinned toolchain, CI previews, dependency and security scanning, release automation, and a gated formal-publication workflow.

Development previews
